📚 Lecture 1 — Quick Summary

Computer Science

Computer Science is the study of computers, algorithms, and problem-solving. It includes theoretical foundations and practical applications.

Programming

Programming is writing instructions that a computer can understand and execute, step by step.

Hardware & Software

Hardware is the physical equipment. Software is the programs/instructions that control hardware.

Computer Units

Input, Output, Memory, ALU, Control Unit, and Secondary Storage are the logical units discussed in Lecture 1.

Data Hierarchy

Bit → Character → Field → Record → File → Database.

Languages

Machine language uses binary; assembly uses mnemonics; high-level languages use more human-readable statements.

Why C++?

C++ is presented as a general-purpose, compiled, high-performance language used in games, operating systems, finance, simulations, and embedded systems.

Program Development

Analyze the problem → design an algorithm → implement it in code → verify → maintain the program.

💻 First C++ Program

#include <iostream>
using namespace std;

int main() {
    cout << "Welcome to Computer Science with C++!" << endl;
    return 0;
}
#include <iostream>
Provides input/output facilities.
using namespace std;
Makes standard-library names simpler to write.
int main()
The starting point of the program.
return 0;
Indicates successful completion.
