🧠 Learn Before You Practice

Computer Science

Study of computers, algorithms and problem-solving.

Remember: CS includes theoretical foundations and practical applications.

Programming

Writing instructions a computer can understand and execute.

Idea: A program tells the computer what to do step by step.

Hardware vs Software

Hardware = physical components. Software = programs/instructions.

Examples: keyboard, screen, memory and CPU are hardware.

Computer Units

Input · Output · Memory · ALU · Control Unit · Secondary Storage.

ALU: calculations and logical operations. Control Unit: directs operations.

Data Hierarchy

Bit → Character → Field → Record → File → Database.

Example: a record is a collection of related fields.

Programming Languages

Machine → Assembly → High-level.

Machine: 0s and 1s. Assembly: mnemonics + assembler. High-level: more human-readable statements.

Why C++?

General-purpose, compiled, high-performance language.

Uses in the material: games, operating systems, finance, simulations and embedded systems.

Program Development

Analyze → design algorithm → implement → verify → maintain.

Algorithm: a step-by-step problem-solving process.
